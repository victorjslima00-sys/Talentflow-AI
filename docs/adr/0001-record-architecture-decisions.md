# 1. Registro de Decisões de Arquitetura (ADRs)

Data: 2026-10-29  
Status: Aceito

## Contexto
Projetos complexos exigem clareza sobre os motivos que levaram a determinadas escolhas técnicas. Para garantir rastreabilidade, facilitar o onboarding e permitir defesa técnica em entrevistas de portfólio, adotamos o padrão Architecture Decision Records (ADRs).

## Decisão
Registraremos todas as decisões de arquitetura e governança em arquivos Markdown numerados sequencialmente em `docs/adr/`. Toda nova decisão relevante ou alteração substancial deve gerar um novo ADR aprovado no Pull Request.

## Consequências
- Histórico transparente e auditável de cada escolha técnica.
- Eliminação de suposições tácitas na base de código.
